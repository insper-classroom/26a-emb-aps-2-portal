#Portal Gun
Nesse projeto vamos desenvolver um controle para o jogo Portal 2 utilisando a raspbery-pi pico 2, para maior imerção vamos reproduzir a iconica portal gun com cotroles de movimento para a mira e agarar objetos, botões para cada um dos portais e um analogico para controlar a movimatação
##inputs
-Botão portal azul
-Botão portal laranja
-Botão reset imu
-Botão agachar
-Analogico
-IMU
##Componentes
-Raspbery-pi pico 2
